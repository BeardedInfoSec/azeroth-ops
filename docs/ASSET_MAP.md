## Design rule

CoD owns the combat layer (guns, gun/FX audio, perk machines, sentry/UAV concepts, HUD style). WoW owns the world layer (cities, props, races, zombies/ghouls, zeppelin). ORIGINAL code fills gaps and glues them together.

### Violations and ambiguities

- **VIOLATION: Hit-confirmation sound is a synthesized sine blip.** Combat-layer audio that is not CoD. Recommendation: Extract a BO2 hitmarker alias (mpl_common.all family) with scripts/import-audio.ps1, or document the blip as intentional.
- **VIOLATION: Survival barricade/board/breach sounds are oscillator sweeps.** Zombies combat feedback is synthesized (README admits it). Recommendation: Import BO2 zombie barricade aliases (zm banks) or keep and label as placeholder.
- **VIOLATION: Sentry and UAV have no CoD presentation.** Sentry is box meshes; UAV is a radar reveal only. Recommendation: Import a BO2 sentry model (named-model path used by import-cod-props.ps1) and UAV/sentry alias audio. Another agent may be adding sentry assets; classify any new folder in this table.
- **AMBIGUITY: Perk machines mix CoD mesh with original signage.** BO2 GLB (combat) placed inside WoW cities; canvas sign() and box collider are original and remain as fallback. Recommendation: Keep: mesh and textures are CoD, collision and fallback are original code. Prefer the BO2 logo textures already bundled over canvas text.
- **AMBIGUITY: Zeppelin placeholder vs real WoW zeppelin.** README says both that Battle Royale uses the original Wrath hull and that the zeppelin is an original prototype visual. Recommendation: Fix README wording: the WoW hull is the product; the procedural zeppelin is only a loading stand-in.
- **AMBIGUITY: Procedural fortifications and fountain water inside the WoW world layer.** World-layer visuals that are original rather than WoW. Recommendation: Acceptable. Where practical swap carts/crates for imported WoW doodads (props/).
- **AMBIGUITY: Playable races and zombies are WoW meshes carrying BO2 guns.** Intended hybrid: WoW actors in the world, CoD weapons in hand. Hit regions are approximated by height. Recommendation: Keep; this is the project premise.
- **AMBIGUITY: public/ui menu art is a rendered mix.** In-game screenshots may contain WoW geometry plus CoD models or HUD. Recommendation: Treat as non-redistributable (git-ignored). Regenerate with capture-menu-art.cjs if provenance matters.
- **AMBIGUITY: cod-theme.css imitates CoD styling.** Code is original (MIT) but visually evokes CoD; no CoD files are included. Recommendation: Fine for a parody project; do not add CoD logos or fonts.
- **AMBIGUITY: Layouts saved under public/assets/layouts/ are ORIGINAL data inside an ignored folder.** public/assets/ is git-ignored, so user layouts are never committed. Recommendation: Move layouts to a tracked location if sharing them is wanted.

## New asset folders

The builder fails (exit 1) when a directory under `public/assets` or `public/ui` has no entry in the `CLASSIFICATION` table in `scripts/build-asset-map.cjs`. Add the entry, choose the origin, and keep `redistributable: false` for anything extracted from a game.
